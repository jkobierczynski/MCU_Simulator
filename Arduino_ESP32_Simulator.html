Getting a .hex

        Arduino IDE: Sketch → Export Compiled Binary, then use yoursketch.ino.hex (not the with_bootloader one).

        arduino-cli: arduino-cli compile -b arduino:avr:uno --output-dir out yoursketch
        
What's emulated

        CPU, GPIO, timers 0–2 (millis, delay, PWM, tone, Servo), USART (Serial), ADC, external and pin-change interrupts, EEPROM, SPI/TWI registers.
        The modules are decoded electrically from the pins: LED, RGB, 7-segment, buttons, switches, potentiometer, LDR, joystick, PIR, relay, buzzer (frequency), servo (pulse width), stepper (coil sequence), HC-SR04 (real echo pulse) and the parallel LCD (HD44780 4-bit bus).
        
Sketch mode only

        NeoPixel, DHT, DS18B20, BME280, I²C LCD and OLED, because those need protocol-level device models.
